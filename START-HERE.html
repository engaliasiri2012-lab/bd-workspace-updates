BD Workspace 2.0.3

اكتشاف فرص BD، تحليل ملفاتك، أخبار الطاقة السعودية، وإنشاء تقارير قابلة للتعديل.

التثبيت مرة واحدة

  1. أوقف تشغيل النسخة القديمة بالضغط على Ctrl+C في نافذتها السوداء.
  2. فك ضغط الملف بالكامل وافتح مجلد BD-Workspace.
  3. اضغط Alt+D ثم اكتب cmd واضغط Enter.
  4. اكتب py -3 install.py واضغط Enter.
  5. افتح المنصة لاحقًا من اختصار BD Workspace على سطح المكتب. اترك نافذة التشغيل مفتوحة.

بياناتك السابقة تبقى في %LOCALAPPDATA%\MidadBDWorkspace ويستخدمها البرنامج تلقائيًا. لا تحذف هذا المجلد. عند التثبيت على جهاز جديد يبدأ دليل الشركات فارغًا.

أربع وظائف واضحة

  1. اكتشاف فرص BD: اختر القطاع واكتب كلمة مفتاحية، ثم راجع المصدر والتاريخ لكل نتيجة.
  2. تحليل ملفاتي: اسحب تقرير اكتفاء أو الحفر، حدد الملفات، واضغط «حلّل الملفات المختارة».
  3. أخبار الطاقة السعودية: اضغط «حدّث أخبار السوق الآن»، أو فعّل التحديث عند فتح الصفحة مرة يوميًا.
  4. إنشاء التقارير: اختر بحثًا محفوظًا، راجعه، ونزّله Word أو PowerPoint أو PDF.

أضف مفتاح OpenAI API من الإعدادات؛ يلزم رصيد API لإجراء البحث والتحليل. لا يوجد ربط بالبريد في هذا الإصدار. الصور وPDF المصور تحتاج OCR، وروابط المصادر تستلزم المراجعة قبل التواصل التجاري.
